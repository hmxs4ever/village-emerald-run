# Village Emerald Run

Solo Resident Evil 4 (RE Engine) mashup. The village clearing is a short Frontiers-style run: rings, a boost, one gate, a timed stretch, and a Chaos Emerald. Leon keeps his handgun. Sonic Frontiers is the idea only. This package does not ship Frontiers files and does not need that game installed.

## What a player does

1. Install from Melty. Melty installs REFramework. This script lands in `reframework/autorun`.
2. Load a village save. Stand in the clearing, face the open ground, press F6. That plants the course.
3. Hold Left Shift to boost along the gold rings. Aim and shoot as usual.
4. Cross the cyan gate. The timer starts, and the script asks the current RE4 track to play faster.
5. Reach the green emerald. F7 resets the run without moving the course.

## Status

Source and package are built. Not launched against a RE4 install from this machine: the game folder is not mounted here. Treat the in-game feel as untested until you press Test in the Melty app.

Loader: REFramework, which Melty installs by itself. No extra player install.
